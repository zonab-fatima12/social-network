# Social Network Platform

A responsive and interactive Social Network Platform developed as part of my internship project.

## Features

- User Profiles
- Create and Display Posts
- Like Posts
- Comments
- Friend Requests
- Notifications
- Search Functionality
- Responsive Design
- Interactive User Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Main webpage
- `style.css` – Styling and responsive design
- `script.js` – Interactive functionality

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. The Social Network Platform will open in your browser.

## Internship Task

This project was developed as part of my internship assignment to demonstrate frontend web development skills and interactive social networking features.
